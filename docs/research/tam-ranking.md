# Largest addressable market by city (2026-10-26)

Ranked by owner-occupied households (Census ACS 2024 1-year, table B25003, place level, downloaded from the ACS summary file) in cities whose main utility publishes hardness of 121 mg/L or more, which USGS classes as hard (121-180) or very hard (over 180). Source for classes: https://www.usgs.gov/water-science-school/science/hardness-water

No dollar TAM: no sourced per-household softener spend was found, so the ranking is on households. Hardness is one figure per utility; a city's share of homes on each source is not published for mixed cities (Los Angeles, Philadelphia), so those are flagged rather than discounted.
